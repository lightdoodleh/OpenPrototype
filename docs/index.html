受控更新流程 ● Agent ready
  1. 01 标出需求增量

    在 PRD 里只标出本次要变的字段或规则。

  2. 02 自动携带上下文

    Agent 同时获得当前 HTML、对应 PRD 和项目规范。

  3. 03 同步相关文件

    页面、PRD 与 mock 数据按同一事实边界更新。

  4. 04 运行红线检查

    静态规则与浏览器冒烟在评审前暴露偏差。

为什么在线版不直接运行 Agent？ OpenPrototype 默认只在本机工作，文件修改和 Agent 接口不开放到公网。这份页面只用于零安装体验。

OpenPrototype 是 MIT 许可的开源项目。在线演示不收集输入、不持久化示例数据，也不会连接本机或云端模型。
