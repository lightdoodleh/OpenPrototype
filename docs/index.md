# OpenPrototype 在线只读演示 PRD

## 页面目标

让未安装 Node、OpenCode 或 OpenPrototype 的访客直接理解并体验核心工作流：

1. 在左侧选择客户列表、客户详情或 PRD。
2. 在客户列表中按名称、状态筛选示例数据。
3. 从列表进入客户详情，只读查看字段。
4. 在 PRD 中看到需求增量标记及其影响范围。
5. 从页面跳转 GitHub 或复制本地安装命令。

## 事实边界

- 在线版本只展示浏览和筛选，不调用 Agent、不写文件、不持久化数据。
- 本地版本才提供 Agent 修改、PRD 保存、文件创建和红线检查。
- 示例数据仅用于说明交互，不代表真实客户或业务。

## 字段与状态

| 字段 | 说明 |
|---|---|
| 客户名称 | 支持模糊筛选 |
| 联系人 | 列表与详情展示 |
| 联系电话 | 列表与详情展示 |
| 客户等级 | A / B / C 类 |
| 状态 | 启用 / 停用 |
