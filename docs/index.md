# OpenPrototype 在线只读演示 PRD

## 页面目标

让未安装 Node、OpenCode 或 OpenPrototype 的访客直接理解并体验核心工作流：

1. 在左侧页面树选择客户列表或客户详情。
2. 在客户列表中按名称、状态筛选示例数据。
3. 从列表进入客户详情，只读查看字段。
4. 点击预览窗口右下角的 PRD 按钮，以抽屉形式查看当前页面对应的 PRD、需求增量标记及影响范围。
5. 在右侧 OpenCode Agent 面板查看当前 HTML / PRD 上下文、示例对话与执行过程，并可进行不联网的模拟对话。
6. 从页面跳转 GitHub 或复制本地安装命令。

## 事实边界

- 在线版本展示浏览、筛选、PRD 抽屉与 Agent 模拟对话，不调用真实 Agent、不写文件、不持久化数据。
- 本地版本才提供 Agent 修改、PRD 保存、文件创建和红线检查。
- 示例数据仅用于说明交互，不代表真实客户或业务。

## 工作台布局与交互

- 左栏只展示原型页面树，PRD 不作为页面节点出现。
- 中间栏为原型预览窗口；右下角固定展示纵向 PRD 按钮。
- 点击 PRD 后，在预览窗口内部从右侧展开当前页面对应的 PRD 抽屉；关闭后回到原型预览。
- 右栏还原真实 OpenCode Agent 面板，包括连接状态、当前页面与 PRD 上下文、快捷操作、对话消息、工具执行状态、输入框、新对话和收起操作。
- 在线 Agent 对话仅在当前页面内模拟响应，明确标注不连接本机模型。

## 字段与状态

| 字段 | 说明 |
|---|---|
| 客户名称 | 支持模糊筛选 |
| 联系人 | 列表与详情展示 |
| 联系电话 | 列表与详情展示 |
| 客户等级 | A / B / C 类 |
| 状态 | 启用 / 停用 |

## 响应式要求

- 桌面端保持“页面导航 / 原型预览 / OpenCode Agent”三栏。
- 平板端 Agent 面板移动到预览下方，仍保留完整对话界面。
- 窄屏下改为纵向排列，页面切换入口、PRD 按钮和 Agent 输入框保持可见。
